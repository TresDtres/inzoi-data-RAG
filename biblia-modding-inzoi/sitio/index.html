La Biblia del Modding en inZOI

Toda la ayuda posible para crear mods con el inZOI ModKit, organizada por los 12 departamentos de MY MOD PROJECTS. Cada departamento explica que se puede construir, que reglas deben cumplir los assets para funcionar en el juego, como usarlo paso a paso, y ejemplos de codigo con Lua y scripts. Incluye 10864 documentos oficiales navegables del corpus.

Departamentos del ModKit

C

Create A Zoi (CAZ)

Personajes: prendas, pelo, accesorios, piel, rasgos faciales. El flujo base del modding visual de inZOI.
B

Build (muebles y objetos)

Muebles, props y materiales de construccion: desde el catalogo vanilla o desde Blender, con reglas de mesh y colision.
V

Vehicle

Vehiculos: general, apariencia, animaciones, slots, objetos y bounds. El proyecto mas estructurado del ModKit.
A

Animation

Animaciones de personaje: locomotion, interacciones y Animation Events (AnimNotify) para enganchar meshes, FX, sonido y scripts.
D

Data Asset

Datos del juego: stats, relaciones, emociones, trabajos. La via de mods de datos puros copiando tablas vanilla y sobrescribiendo filas.
S

Object Sound

Sonidos por objeto y por estado de interaccion: asignar audio a muebles e instrumentos paso a paso.
F

Camera Filters

Filtros de color de camara (LUT 256x16, thumbnail y meshes de preview). Aparece en el editor como Camera Filters y CameraFilter.
T

Content Template

Plantillas de contenido: partir de una estructura ya montada (p.ej. plantilla de vehiculo) y reemplazar los assets por los nuestros.
Tr

Translation

Traducciones y localizacion de mods: archivos PO/PO del workspace, entradas de texto y como montar el pipeline de idiomas.
L

Script (Lua)

Mods de Lua en vivo: la API completa (B1/B2/common), el editor de scripts del ModKit y el ciclo mount/reload sin reiniciar el juego.
U

User Interface

UI mods: mini-apps web (HTML+CSS+JS) sobre el juego, con manifiesto de triggers y el SDK inzoi para hablar con el juego.
0

Blank y fundamentos

Proyecto vacio y fundamentos del ModKit: instalacion, workspace, editor, empaquetado, publicacion y triaje de problemas.
