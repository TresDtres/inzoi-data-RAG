## 🧩 Struct: FB1ObjectDataFilterRow

Defines tags used to filter objects in UI or gameplay logic.

### Properties

- **Id** (`FName`): Unique identifier for the data filter.
- **Tags** (`TArray<FName>`): List of tags used to group or filter objects.
