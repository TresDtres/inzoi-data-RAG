## 🎛️ Enum: EB1SlotUsageType

Describes how a slot can be used based on the number of occupants.

- **Invalid**: Indicates an invalid or uninitialized value.
- **None**: Does not use the slot.
- **Single**: Uses one slot.
- **Double**: Uses two slots.
