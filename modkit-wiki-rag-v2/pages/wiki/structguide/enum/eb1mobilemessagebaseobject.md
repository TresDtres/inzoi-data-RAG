## 🎛️ Enum: EB1MobileMessageBaseObject

Specifies the target object type for mobile messages.

- **Self**: The referencing object (ScriptContext@SelfObject).
- **Target**: The target of the interaction (ScriptContext@TargetObject).
- **Player**: The player character being controlled.
- **System**: A system-level object or message.
