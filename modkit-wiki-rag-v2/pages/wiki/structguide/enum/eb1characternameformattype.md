## 🧾 Enum: EB1CharacterNameFormatType

Specifies the formatting order of character names, based on cultural or regional preferences.

- **FirstNameLastName**: Displays name in "First Name Last Name" format (e.g., John Smith).
- **LastNameFirstName**: Displays name in "Last Name First Name" format (e.g., Smith John).
