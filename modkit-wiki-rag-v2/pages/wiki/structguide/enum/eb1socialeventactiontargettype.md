## 🎛️ Enum: EB1SocialEventActionTargetType

Determines the type of target a social event action applies to.

- **None**: Indicates that no specific value is selected.
- **Role**: Retrieves characters assigned to a specific role in a site event, excluding those already performing the action..
- **Object**: Retrieves entities linked to a specific object within the site
