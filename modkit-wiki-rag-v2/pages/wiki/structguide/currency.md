## 🧩 Struct: FB1CurrencyTableRow

Defines an in-game currency type with UI display settings and color scheme.

### Properties

- **Id** (`FName`): Unique identifier for the currency.
- **CurrencyInfo** (`FB1CurrencyInfo`): UI display and behavior flags for this currency.
- **CurrencyColor** (`FB1CurrencyColor`): Color data used for positive/negative changes in UI.
