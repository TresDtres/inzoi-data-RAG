| NameTypeRequiredDefaultDescriptionfloor_levelintyes—Floor level whose wall height changes. Storeys ABOVE this one on the same building move up with it; storeys below are untouched (below ground it is the other way round: this level down to the lowest basement).target_heightfloatyes—Target wall height in CENTIMETRES for the whole storey. In-game presets: 285/300/375/390/465/480/555/570.xfloatno—Site-relative X in CENTIMETRES anywhere near a wall of the target building. Give x AND y to pick the building by position - preferred over wall_key.yfloatno—Site-relative Y in CENTIMETRES anywhere near a wall of the target building (used together with x)wall_keystringno—Exact wall edge key from build.scan_walls, used only when x/y are omitted. Identifies which BUILDING to change, not which wall. Pass the 'edge_key_str' field, i.e. the digits as a STRING - edge keys are int64 values that get mangled when sent as JSON numbers. Prefer x/y.face_dir_xfloatno0Anchor face direction X. Only reproduces a specific in-game drag; leave at 0.face_dir_yfloatno0Anchor face direction Y. Leave at 0.face_dir_zfloatno0Anchor face direction Z. Leave at 0.is_roomboolnofalseMarks the selection as a room rather than a bare wall, matching how the in-game UI reports what was clicked. It does NOT narrow the scope - the whole storey still changes. Leave false unless reproducing a UI interaction.is_rootboolnofalseMarks the room as the root room of its wall graph, again only mirroring the UI selection. Does not narrow the scope. Leave false. |
