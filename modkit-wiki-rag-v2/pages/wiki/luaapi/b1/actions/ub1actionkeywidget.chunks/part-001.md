# Overview

- Widget that automatically displays the key icon bound by an InputAction's MappingName. Auto-switches by keyboard/gamepad input type, auto-detects Chord Actions (combo keys) and shows modifiers, and auto-refreshes when key customization changes. Example: SetActionByMappingName("ToggleMapAction") -> keyboard mode: [M] -> gamepad mode: [Y] + [X] (Chord Action auto-detected).
