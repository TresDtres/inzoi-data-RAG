| NameTypeDescription`BreakDistance``number`IK working distance (cm). When the main-sub distance exceeds this, IK alpha fades to 0. Can differ per combination (e.g. shorter for a child sub).`DistanceHeightScale``number`Shared contact height change per cm of horizontal separation from abs(SideOffset). Zero disables it.`HeightOffset``number`Z offset (cm; negative is down) added to the midPoint - common to main/sub.`LeadTime``number`Velocity-proportional lead time (seconds). forwardLead = mainSpeed * LeadTime; places the sub's path target ahead of the main so it chases then follows. Auto 0 when the main is stopped.`MainRate``number`Main locomotion playback rate (auto-scales root-motion-based move speed). A single value per category combination. E.g. adult-male main + child sub -> 0.5 (walks slowly).`MaxDistanceHeightLowering``number`Maximum lowering of the shared contact when closer than SideOffset (cm).`MaxDistanceHeightRaising``number`Maximum raising of the shared contact when farther than SideOffset (cm).`SideOffset``number`Side distance (cm) from the main when the sub follows.`SubDefaultRate``number`Default sub LocomotionPlayRate. Fixed to this value within the snap zone (50 cm in front to behind the lead-off position).`SubForwardOffset``number`Sub character: own forward offset (cm).`SubHeightOffset``number`Sub-only Z offset (cm) for height-difference correction; applied additionally only to the sub.`SubMaxRate``number`Upper limit of the sub LocomotionPlayRate. Reaches this value when more than 300 cm behind the lead-off (linearly interpolated 50-300).`TowardTargetOffset``number`Sub character: offset toward the partner (cm; negative means toward self). |
