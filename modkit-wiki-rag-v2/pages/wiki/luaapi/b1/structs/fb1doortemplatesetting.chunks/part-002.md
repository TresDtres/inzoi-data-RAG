| NameTypeDescription`DoorAnimationType`[`EB1DoorAnimationType`](https://mod-docs.playinzoi.com/docs/modkit-docs/wiki/luaapi/b1/enums/eb1dooranimationtype)The type of door animation to use (hinged, sliding, garage, double).`DoorCloseAudioId``string`Audio resource ID played when the door closes.`DoorClosingTime``number`Duration in seconds for the door to fully close.`DoorLocationCurve``any`Curve defining door location movement for sliding and garage doors.`DoorMeshName``string`The name of the primary door mesh component.`DoorOpenAnimId1``string`Character animation ID played when the door is opened (primary).`DoorOpenAnimId2``string`Character animation ID played when the door is opened (secondary).`DoorOpenAudioId``string`Audio resource ID played when the door opens.`DoorOpeningTime``number`Duration in seconds for the door to fully open.`DoorRotationCurve``any`Curve defining door rotation movement for garage doors.`MaxDoorOpeningAngle``number`Hinged Door exclusive property Maximum opening angle for hinged doors (degrees).`SecondDoorMeshName``string`The name of the secondary door mesh component (for double hinged doors).`bDoorAnimUse``boolean`Currently there is no separate door motion and it is handled by logic. This bool variable only checks whether to play the animation logic. If door animations are added in the future, please request modifications from the tech team or me. Whether to play the door animation logic.`bDoorLockNotUse``boolean`Whether door lock functionality is disabled for this door. |
