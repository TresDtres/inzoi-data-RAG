| NameTypeDescription`AutonomyTalkModifier``integer`Modifier that increases or decreases the probability of conversations with a character who has this flag when in autonomy. Must be an integer. All characters start with a base score of 100, and this modifier is added to it. The integer modifier added to the base autonomy talk score for characters with this flag.`Category``string`A character cannot have multiple relationship flags with the same category at the same time. When adding a relationship flag, if there's already a flag with the same category, the new flag overwrites the existing one. The category of this relationship flag; only one flag per category can be active at a time.`EndScriptIds``string[]`Scripts triggered when this relationship flag is removed. The list of script IDs executed when this relationship flag is removed.`Index``integer`This is the unique value for the given relationship flag. It must not overlap with values of other relationship flags and should start from 0. Since it's used internally as a bit position, there is a limit to the maximum value. If the limit is reached, you'll need to request an implementation update to increase the maximum. Once a value is assigned, any future changes must ensure backward compatibility. The unique bit index for this relationship flag; must be non-overlapping and start from 0.`LifeTime``integer`Duration (in minutes) this relationship flag lasts. -1 means unlimited. The duration in minutes this flag remains active; -1 means it lasts indefinitely.`NegativeRelationshipStatModifier``number`Modifier for the relationship stat loss when talking to a character with this flag in autonomy. It's a multiplier and must be a float. The float multiplier applied to negative relationship stat losses when this flag is active.`PositiveRelationshipStatModifier``number`Modifier for the relationship stat gain when talking to a character with this flag in autonomy. It's a multiplier and must be a float. The float multiplier applied to positive relationship stat gains when this flag is active.`RemoveOnSelfDeath``boolean`Whether to remove this relationship flag from dying Zoi. (Dying Zoi -> Zoi related to the Dying Zoi) Whether this flag is removed from the dying Zoi when they die.`RemoveOnTargetDeath``boolean`Whether to remove this relationship flag from dying Zoi. (Zoi related to the Dying Zoi -> Dying Zoi) Whether this flag is removed from related Zoi when the flag holder dies.`StartScriptIds``string[]`Scripts triggered when this relationship flag is added. The list of script IDs executed when this relationship flag is added. |
