only valid when the other party is not a system.`bIsIgnored``boolean`Whether the other character ignored this message instead of responding.`bIsNeedConvertMessage``boolean`Whether the message text requires runtime conversion to insert dynamic content.bIsPlainText boolean Whether this message was created from a plain text string rather than a string table entry. bIsRead boolean Whether the player has opened and read this message. bIsSend boolean Whether this message was sent by the player (true) or received from another character (false). bIsWait boolean Whether this message is waiting for a script to resolve before being displayed. bNeedResponse boolean Whether this message is awaiting a response from the player. bNeedResponseReply boolean Whether this message requires a follow-up reply after the player's response. bSetResponseTimer boolean Whether the response timer has been set for this message. bUseSendTable boolean Whether this message was created from a send-message table (player-initiated). |
