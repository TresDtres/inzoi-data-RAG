| NameTypeDescription`CurrencyDatas``FB1CurrencyDefaultData[]`Default currency grants provided to this family at creation.`DescriptionTextId``string`Localized text ID for this family's description.`FamilyMemberList``FB1FamilyMemberAttributeInfo[]`List of attribute IDs applied to all members of this family.`FamilyNameTextId``string`Localized text ID for this family's name.`InitCollectionObjectIds``string[]`List of collection object IDs granted to this family at creation.`InitialBusinesses``FB1FamilyInitialBizInfo[]`Businesses this family owns from world generation. Plain table data, so the save file gains nothing.`InitialCareers``FB1FamilyInitialCareerInfo[]`Careers the members of this family already hold at world generation. Multiple entries per member are allowed when they target different career types.`InitialRelationships``FB1FamilyInitialRelationshipInfo[]`Initial relationship seeds applied after every member of this family has been spawned.`IsRandomGenerate``boolean`Whether this family's members are randomly generated.`MapId``string`Map ID where this family starts.`TextureId``string``bBlockRandomCareer``boolean`true blocks the world-generation fallback that joins one member to a random fake company. Members then keep only the careers authored in FamilyMemberList / InitialCareers. Defaults to true: a preset family's jobs come from authored data, not from a random draw. Set false explicitly on a family that should receive the random fallback. Note this does not block school enrollment - FB2CareerComponent::HandleAutoJoinCareerSchool runs after world generation and is unaffected. |
