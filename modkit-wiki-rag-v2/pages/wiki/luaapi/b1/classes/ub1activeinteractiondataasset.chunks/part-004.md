ThrowHitLandingSpeed number Absolute linear speed at or below which a thrown object counts as having come to rest on a horizontal surface, disarming hit detection. Unit: cm/s. ThrowHitMinImpactSpeed number Minimum impact speed for a thrown object to register a ThrowHit on a character. Unit: cm/s. Measured as NormalImpulse / Mass (velocity change along the contact normal) so it stays frame-rate independent. Below this, a slow object merely rolling/leaning into a character does not trigger an effect (prevents packet/effect spam). |
