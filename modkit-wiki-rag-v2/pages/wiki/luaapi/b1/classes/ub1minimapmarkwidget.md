# Overview

- DisableNativeTick: a class that does not use NativeTick. Without this meta, ClassRequiresNativeTick=true forces every instance to tick. With the meta, it switches to the Auto rule so only instances playing the mission anim (Anim_Mission_Loop) tick; non-mission marks do not.
