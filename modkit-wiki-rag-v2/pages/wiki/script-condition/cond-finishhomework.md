# Description

Checks whether the BaseObject character has completed homework in hand or inventory and has no unfinished homework in those same locations.

# Parameters

| ParameterDescriptionBaseObjectThe character whose hand and inventory are inspected.CompareTypeEqual checks the condition is satisfied; NotEqual negates it. |
| --- |
| BaseObjectThe character whose hand and inventory are inspected.CompareTypeEqual checks the condition is satisfied; NotEqual negates it. |
| CompareTypeEqual checks the condition is satisfied; NotEqual negates it. |
