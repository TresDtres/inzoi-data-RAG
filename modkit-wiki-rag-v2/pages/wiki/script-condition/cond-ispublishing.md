# Description

Checks whether the BaseObject character is currently publishing. A character is considered publishing if they have at least one active royalty contract.

# Parameters

| ParameterDescriptionBaseObjectThe character entity to check publishing status.CompareTypeSupported compare types: Equal, NotEqual. |
| --- |
| BaseObjectThe character entity to check publishing status.CompareTypeSupported compare types: Equal, NotEqual. |
| CompareTypeSupported compare types: Equal, NotEqual. |
