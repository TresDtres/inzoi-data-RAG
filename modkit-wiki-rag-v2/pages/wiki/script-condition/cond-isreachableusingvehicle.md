# Description

Checks whether the target location is reachable using vehicle autonomous driving. (applicable only when BaseObject is Self.)

# Parameters

| ParameterDescriptionBaseObjectThe vehicle object used as the reference (Self or Target).CompareTypeThe type of comparison operation (Equal or NotEqual). |
| --- |
| BaseObjectThe vehicle object used as the reference (Self or Target).CompareTypeThe type of comparison operation (Equal or NotEqual). |
| CompareTypeThe type of comparison operation (Equal or NotEqual). |
