# Description

Checks if a flea market can be started at the specified site. Returns true if no flea market is already planned in the site and the character is eligible to start one.

# Parameters

| ParameterDescriptionBaseObjectThe site context entity to check if a flea market is already planned in site.CompareTypeSupported compare types: Equal, NotEqual. |
| --- |
| BaseObjectThe site context entity to check if a flea market is already planned in site.CompareTypeSupported compare types: Equal, NotEqual. |
| CompareTypeSupported compare types: Equal, NotEqual. |
