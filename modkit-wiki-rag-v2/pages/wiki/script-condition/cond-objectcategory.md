# Description

Checks the ObjectCategory of the specified BaseObject against a given category name.

# Parameters

| ParameterDescriptionBaseObjectThe object to evaluate (resolved to a FB2GameObject)CompareTypeComparison operator: Equal, NotEqualS1ObjectCategory name to compare against (FName) |
| --- |
| BaseObjectThe object to evaluate (resolved to a FB2GameObject)CompareTypeComparison operator: Equal, NotEqualS1ObjectCategory name to compare against (FName) |
| CompareTypeComparison operator: Equal, NotEqualS1ObjectCategory name to compare against (FName) |
| S1ObjectCategory name to compare against (FName) |
