# Description

Checks whether the BaseObject student is marked absent in today's school daily record. A student becomes absent when today's school evaluation closes without attendance.

# Parameters

| ParameterDescriptionBaseObjectThe student character to evaluate.CompareTypeEqual checks the student is absent; NotEqual negates it. |
| --- |
| BaseObjectThe student character to evaluate.CompareTypeEqual checks the student is absent; NotEqual negates it. |
| CompareTypeEqual checks the student is absent; NotEqual negates it. |
