# Description

Checks whether Self and BaseObject graduated from the same school (matching CareerDtId). Records with CareerDtId=NAME_None (legacy/NPC) are excluded from matching.

# Parameters

| ParameterDescriptionBaseObjectTarget character to compare graduation school with.CompareTypeEqual (same school) / NotEqual (different school).S1EB1EducationType filter (optional). Empty matches any education. |
| --- |
| BaseObjectTarget character to compare graduation school with.CompareTypeEqual (same school) / NotEqual (different school).S1EB1EducationType filter (optional). Empty matches any education. |
