# Description

Checks whether BaseObject is the valedictorian of the school it belongs to. Returns false (regardless of CompareType) if BaseObject isn't enrolled at a school.

# Parameters

| ParameterDescriptionBaseObjectThe character to check.CompareTypeEqual (is valedictorian) / NotEqual (is not). |
| --- |
| BaseObjectThe character to check.CompareTypeEqual (is valedictorian) / NotEqual (is not). |
| CompareTypeEqual (is valedictorian) / NotEqual (is not). |
