# Description

Checks whether the current day matches the active Calendar Event defined by the given ID.

# Parameters

| ParameterDescriptionBaseObjectNot used. Internally fixed to Self.CompareTypeSupported compare types: Equal, NotEqualS1Calendar Event ID defined in the CalendarEvent data table |
| --- |
| BaseObjectNot used. Internally fixed to Self.CompareTypeSupported compare types: Equal, NotEqualS1Calendar Event ID defined in the CalendarEvent data table |
| CompareTypeSupported compare types: Equal, NotEqualS1Calendar Event ID defined in the CalendarEvent data table |
| S1Calendar Event ID defined in the CalendarEvent data table |
