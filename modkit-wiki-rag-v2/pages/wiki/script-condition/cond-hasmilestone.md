# Description

Checks if the BaseObject character has achieved the specified milestone.

# Parameters

| ParameterDescriptionBaseObjectThe character to check (Self or Target).CompareTypeEqual: has the milestone / NotEqual: does not have the milestone.S1Milestone ID (Milestone.Json) to check. |

| BaseObjectThe character to check (Self or Target).CompareTypeEqual: has the milestone / NotEqual: does not have the milestone.S1Milestone ID (Milestone.Json) to check. |
| CompareTypeEqual: has the milestone / NotEqual: does not have the milestone.S1Milestone ID (Milestone.Json) to check. |
