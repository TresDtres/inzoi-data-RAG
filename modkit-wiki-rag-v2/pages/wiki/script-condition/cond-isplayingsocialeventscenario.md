# Description

Checks whether the entity resolved from BaseObject is currently participating in a social event that has its scenario flag active (IsPlayingScenario).

# Parameters

| ParameterDescriptionBaseObjectThe entity to check (Self or Target).CompareTypeEqual: scenario is playing; NotEqual: scenario is not playing. |
| --- |
| BaseObjectThe entity to check (Self or Target).CompareTypeEqual: scenario is playing; NotEqual: scenario is not playing. |
| CompareTypeEqual: scenario is playing; NotEqual: scenario is not playing. |
