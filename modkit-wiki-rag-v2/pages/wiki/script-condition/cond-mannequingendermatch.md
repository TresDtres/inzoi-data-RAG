# Description

Checks whether the Self character's gender matches the Target store mannequin's AppearanceSetting gender.

# Parameters

| ParameterDescriptionBaseObjectSelf (character interacting with mannequin).CompareTypeEqual: gender matches → true. NotEqual: gender differs → true. |
