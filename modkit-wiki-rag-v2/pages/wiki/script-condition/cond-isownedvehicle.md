# Description

Checks whether the target vehicle is owned by the current possessed Zoi.

# Parameters

| ParameterDescriptionBaseObjectThe vehicle used as the reference (Target).CompareTypeThe comparison operation to apply (Equal or NotEqual). |
| --- |
| BaseObjectThe vehicle used as the reference (Target).CompareTypeThe comparison operation to apply (Equal or NotEqual). |
| CompareTypeThe comparison operation to apply (Equal or NotEqual). |
