# Description

Returns true when the school's currently designated uniform for the BaseObject mannequin's body gender matches the designer default (DA) uniform ('no uniform' vs 'has default' counts as not matching; true when both are empty).

# Parameters

| ParameterDescriptionBaseObjectThe school mannequin object (placed on the school site). |
| --- |
| BaseObjectThe school mannequin object (placed on the school site). |
