# Description

Checks whether today falls within a real-world date range defined by the specified condition entry.

# Parameters

| ParameterDescriptionBaseObjectNot used.CompareTypeSupported compare types: Equal (true if within range), NotEqual (true if outside range)S1Condition ID defined in RealDateCondition.json |
| --- |
| BaseObjectNot used.CompareTypeSupported compare types: Equal (true if within range), NotEqual (true if outside range)S1Condition ID defined in RealDateCondition.json |
| CompareTypeSupported compare types: Equal (true if within range), NotEqual (true if outside range)S1Condition ID defined in RealDateCondition.json |
| S1Condition ID defined in RealDateCondition.json |
