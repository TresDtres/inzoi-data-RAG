# Description

Checks whether the BaseObject character is currently holding hands with another character.

# Parameters

| ParameterDescriptionBaseObjectThe entity whose hold-hand state is checked (Self or Target).CompareTypeEqual (is holding hand), NotEqual (is not holding hand). |
| --- |
| BaseObjectThe entity whose hold-hand state is checked (Self or Target).CompareTypeEqual (is holding hand), NotEqual (is not holding hand). |
| CompareTypeEqual (is holding hand), NotEqual (is not holding hand). |
