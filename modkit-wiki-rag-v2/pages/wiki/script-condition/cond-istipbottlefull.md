# Description

Checks whether the tip bottle at the HouseholdBiz site where BaseObject is located is full.

# Parameters

| ParameterDescriptionBaseObjectThe character used to resolve the current HouseholdBiz siteCompareTypeEqual: returns true if the tip bottle is full; NotEqual: returns true otherwise |
| --- |
| BaseObjectThe character used to resolve the current HouseholdBiz siteCompareTypeEqual: returns true if the tip bottle is full; NotEqual: returns true otherwise |
| CompareTypeEqual: returns true if the tip bottle is full; NotEqual: returns true otherwise |
