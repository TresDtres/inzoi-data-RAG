# Description

Checks whether the household of the given BaseObject Character owns at least one HouseholdBizSite. Equal is true if the household has a HouseholdBizSite; NotEqual is true if it does not.

# Parameters

| ParameterDescriptionBaseObjectA Character belonging to a household whose HouseholdBizSite ownership is checked.CompareTypeEqual: true if the household has at least one HouseholdBizSite. NotEqual: true if none. |
| --- |
| BaseObjectA Character belonging to a household whose HouseholdBizSite ownership is checked.CompareTypeEqual: true if the household has at least one HouseholdBizSite. NotEqual: true if none. |
| CompareTypeEqual: true if the household has at least one HouseholdBizSite. NotEqual: true if none. |
