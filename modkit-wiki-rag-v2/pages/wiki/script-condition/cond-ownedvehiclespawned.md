# Description

Checks whether the vehicle owned by the given BaseObject is spawned.

# Parameters

| ParameterDescriptionBaseObjectThe target BaseObject to check whether it owns a spawned vehicle.CompareTypeType of comparison operation (Equal or NotEqual). |
| --- |
| BaseObjectThe target BaseObject to check whether it owns a spawned vehicle.CompareTypeType of comparison operation (Equal or NotEqual). |
| CompareTypeType of comparison operation (Equal or NotEqual). |
