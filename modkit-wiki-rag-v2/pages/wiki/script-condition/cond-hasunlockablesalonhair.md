# Description

Checks whether the customer (BaseObject) has at least one hair in SalonHairPool that is still locked. Used to hide the unlock styling interaction when there are no locked hairs left.

# Parameters

| ParameterDescriptionBaseObjectCustomer. Resolves candidate hairs by gender/age and checks ownership.CompareTypeEqual(has locked hair) / NotEqual(has none).S1Optional category key: "Short"/"Medium"/"Long"/"Ponytail". Empty checks all. |
