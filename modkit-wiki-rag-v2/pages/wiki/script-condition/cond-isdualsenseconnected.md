Checks whether a DualSense controller is connected. PS5: determines the result from the connection state because only DualSense-family pads can connect. Editor: allows a test pad. Other shipping builds (Windows/Mac): always false.

# Parameters

| ParamsDescriptionCompareTypeEqual: connected, NotEqual: not connected |
| --- |
| CompareTypeEqual: connected, NotEqual: not connected |
