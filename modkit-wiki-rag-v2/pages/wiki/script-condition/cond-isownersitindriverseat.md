# Description

Checks whether the given BaseObject (character, vehicle owner) is currently sitting in the driver's seat of their owned vehicle.

# Parameters

| ParameterDescriptionBaseObjectThe character (vehicle owner) to validate (Self or Target).CompareTypeType of comparison operation (Equal or NotEqual). |
| --- |
| BaseObjectThe character (vehicle owner) to validate (Self or Target).CompareTypeType of comparison operation (Equal or NotEqual). |
| CompareTypeType of comparison operation (Equal or NotEqual). |
