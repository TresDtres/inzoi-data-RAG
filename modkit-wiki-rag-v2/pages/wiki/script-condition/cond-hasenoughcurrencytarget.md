# Description

Checks whether the character (Self) has enough currency to purchase the BaseObject based on its sale price.

# Parameters

| ParameterDescriptionBaseObjectThe target object whose sale price will be compared against the character's currencyCompareTypeEqual: Self has enough currency. NotEqual: Self does not have enough currency. |
| --- |
| BaseObjectThe target object whose sale price will be compared against the character's currencyCompareTypeEqual: Self has enough currency. NotEqual: Self does not have enough currency. |
| CompareTypeEqual: Self has enough currency. NotEqual: Self does not have enough currency. |
