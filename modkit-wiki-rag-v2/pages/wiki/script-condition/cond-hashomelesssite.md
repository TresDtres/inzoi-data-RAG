# Description

Checks whether the BaseObject has a registered public homeless site (rough-sleeping fallback). True only for homeless registration (not a formal accommodation booking).

# Parameters

| ParameterDescriptionBaseObjectCharacter whose homeless registration is checkedCompareTypeSupported compare types: Equal, NotEqual |
| --- |
| BaseObjectCharacter whose homeless registration is checkedCompareTypeSupported compare types: Equal, NotEqual |
| CompareTypeSupported compare types: Equal, NotEqual |
