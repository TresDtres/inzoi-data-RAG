# Description

Checks whether the gender of the Self character matches (or does not match) the gender of the Target character.

# Parameters

| ParameterDescriptionBaseObjectNot used; always compares Self and Target directly.CompareTypeSupported compare types: Equal, NotEqual. |
| --- |
| BaseObjectNot used; always compares Self and Target directly.CompareTypeSupported compare types: Equal, NotEqual. |
| CompareTypeSupported compare types: Equal, NotEqual. |
