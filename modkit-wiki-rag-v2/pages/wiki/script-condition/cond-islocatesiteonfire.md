# Description

Checks whether the site where the BaseObject is located is currently on fire.

# Parameters

| ParameterDescriptionBaseObjectThe object whose located site is used for the fire check.CompareTypeType of comparison operation (Equal or NotEqual). |
| --- |
| BaseObjectThe object whose located site is used for the fire check.CompareTypeType of comparison operation (Equal or NotEqual). |
| CompareTypeType of comparison operation (Equal or NotEqual). |
