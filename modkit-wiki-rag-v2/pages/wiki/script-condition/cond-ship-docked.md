# Description

Checks whether the selected ship is docked. If the character is currently boarded on a ship, the boarded ship is checked first; otherwise the target ship is used.

# Parameters

| ParameterDescriptionBaseObjectThe selected ship object (Self or Target).CompareTypeComparison operation type (Equal or NotEqual). |
| --- |
| BaseObjectThe selected ship object (Self or Target).CompareTypeComparison operation type (Equal or NotEqual). |
| CompareTypeComparison operation type (Equal or NotEqual). |
