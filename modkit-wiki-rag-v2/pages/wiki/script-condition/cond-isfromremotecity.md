# Description

Checks whether the BaseObject lives in a city other than the loaded one. Characters pulled into the current city by MoveTogether still count, since their household stays in the origin city.

# Parameters

| ParameterDescriptionBaseObjectCharacter to testCompareTypeEqual: true when the home city differs. NotEqual: true when it matches. |
| --- |
| BaseObjectCharacter to testCompareTypeEqual: true when the home city differs. NotEqual: true when it matches. |
| CompareTypeEqual: true when the home city differs. NotEqual: true when it matches. |
