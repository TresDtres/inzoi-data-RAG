# Description

Checks whether the main perspective ID of the specified character matches the given value (S1).

# Parameters

| ParameterDescriptionBaseObjectThe character whose main perspective will be checked.CompareTypeSupported compare types: Equal, NotEqual.S1The perspective ID to compare against. |

| BaseObjectThe character whose main perspective will be checked.CompareTypeSupported compare types: Equal, NotEqual.S1The perspective ID to compare against. |
| CompareTypeSupported compare types: Equal, NotEqual.S1The perspective ID to compare against. |
| S1The perspective ID to compare against. |
