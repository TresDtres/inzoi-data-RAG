Checks if the BaseObject's ObjectId matches the specified ObjectId (S1).

| BaseObjectThe game object whose ObjectId will be checkedCompareTypeComparison operator: Equal, NotEqualS1The ObjectId to compare against |
| CompareTypeComparison operator: Equal, NotEqualS1The ObjectId to compare against |
| S1The ObjectId to compare against |
