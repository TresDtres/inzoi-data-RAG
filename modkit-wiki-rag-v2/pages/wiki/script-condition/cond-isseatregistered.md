# Description

Checks whether the BaseObject (seat entity) is registered in any Business career. Iterates all Business careers to find if any has the seat registered.

# Parameters

| ParameterDescriptionBaseObjectThe seat entity to check for registration. |
| --- |
| BaseObjectThe seat entity to check for registration. |
