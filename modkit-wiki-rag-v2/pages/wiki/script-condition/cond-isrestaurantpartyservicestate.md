# Description

Checks whether BaseObject customer belongs to a restaurant party in the service state specified by S1. The BaseObject may be any party member; the representative is resolved only to validate party membership.

# Parameters

| ParameterDescriptionBaseObjectSelf or Target customer whose party state is checkedS1EB1RestaurantPartyServiceState FNameCompareTypeEqual: party is in S1. NotEqual: party is not in S1 |
| --- |
| BaseObjectSelf or Target customer whose party state is checkedS1EB1RestaurantPartyServiceState FNameCompareTypeEqual: party is in S1. NotEqual: party is not in S1 |
| S1EB1RestaurantPartyServiceState FNameCompareTypeEqual: party is in S1. NotEqual: party is not in S1 |
| CompareTypeEqual: party is in S1. NotEqual: party is not in S1 |
