# Description

Checks whether Self and Target are located on the same site. Both Self and Target must be valid actors located within a site; otherwise the condition returns false.

# Parameters

| ParameterDescriptionBaseObjectNot used for site lookup — always checks Self vs Target.CompareTypeType of comparison operation (Equal or NotEqual). |
| --- |
| BaseObjectNot used for site lookup — always checks Self vs Target.CompareTypeType of comparison operation (Equal or NotEqual). |
| CompareTypeType of comparison operation (Equal or NotEqual). |
