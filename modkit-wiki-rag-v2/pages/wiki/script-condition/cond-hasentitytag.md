# Description

Checks whether the specified entity has a given tag.

# Parameters

| ParameterDescriptionBaseObjectThe entity to check for the tagCompareTypeEqual (has the tag), NotEqual (does not have the tag)S1The tag name to check |
| --- |
| BaseObjectThe entity to check for the tagCompareTypeEqual (has the tag), NotEqual (does not have the tag)S1The tag name to check |
| CompareTypeEqual (has the tag), NotEqual (does not have the tag)S1The tag name to check |
| S1The tag name to check |
