# Description

Checks whether the specified FoodObject has remaining food (not empty).

# Parameters

| ParameterDescriptionBaseObjectThe food object to validate (Self or Target).CompareTypeEqual: has remaining food. NotEqual: is empty. |
| --- |
| BaseObjectThe food object to validate (Self or Target).CompareTypeEqual: has remaining food. NotEqual: is empty. |
| CompareTypeEqual: has remaining food. NotEqual: is empty. |
