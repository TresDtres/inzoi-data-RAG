# Description

Adds a transient desire stat to the character's autonomy component, temporarily influencing desire priority.

# Parameters

| ParameterDescriptionBaseObjectThe character that receives the transient desire statS1Transient desire stat ID to add to the character's autonomy component |

| BaseObjectThe character that receives the transient desire statS1Transient desire stat ID to add to the character's autonomy component |
| S1Transient desire stat ID to add to the character's autonomy component |
