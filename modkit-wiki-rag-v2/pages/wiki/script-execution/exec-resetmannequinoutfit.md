# Description

Resets the Target store mannequin's designated outfit. Clears bHasDesignatedOutfit and OutfitCategory on B2, then sends S_ChangeMannequinOutfitCategory(None) to trigger B1 ResetDesignatedOutfit.

| ParameterDescriptionBaseObjectTarget (the mannequin to reset). |
