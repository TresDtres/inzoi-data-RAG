# Description

Completes (finishes) a specific Hope currently selected in the specified BaseObject's hope slots. The hope is de-selected and marked as successfully completed rather than cancelled.

# Parameters

| ParameterDescriptionBaseObjectThe character whose hope will be completed (Self or Target).S1The Hope ID to complete (e.g., Preference_Cooking). |
| --- |
| BaseObjectThe character whose hope will be completed (Self or Target).S1The Hope ID to complete (e.g., Preference_Cooking). |
| S1The Hope ID to complete (e.g., Preference_Cooking). |
