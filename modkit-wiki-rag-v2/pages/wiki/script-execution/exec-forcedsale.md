# Description

Forcibly sells the specified game object by requesting a forced sale from the site where the object is located. The BaseObject must be a valid game object with a valid located site ID.

# Parameters

| ParameterDescriptionBaseObjectThe game object to be forcibly sold (Self or Target). |
| --- |
| BaseObjectThe game object to be forcibly sold (Self or Target). |
