# Description

Changes the character's base outfit to the specified outfit category.

# Parameters

| ParameterDescriptionBaseObjectThe character whose base outfit category will be changed (Self or Target).S1Outfit category name to set as the base (e.g. "Casual", "Formal", "Sport"). |
| --- |
| BaseObjectThe character whose base outfit category will be changed (Self or Target).S1Outfit category name to set as the base (e.g. "Casual", "Formal", "Sport"). |
| S1Outfit category name to set as the base (e.g. "Casual", "Formal", "Sport"). |
