# Description

Removes the specified costume from the character's current outfit by costume ID.

# Parameters

| ParameterDescriptionBaseObjectThe character whose outfit will be modified (Self or Target).S1Costume ID to remove (e.g. "CostumeA"). |
| --- |
| BaseObjectThe character whose outfit will be modified (Self or Target).S1Costume ID to remove (e.g. "CostumeA"). |
| S1Costume ID to remove (e.g. "CostumeA"). |
