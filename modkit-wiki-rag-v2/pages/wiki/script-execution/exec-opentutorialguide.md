# Description

Opens the tutorial guide UI for the specified tutorial ID, optionally navigating to a sub-tutorial.

# Parameters

| ParameterDescriptionBaseObjectNot used.S1Tutorial ID to openS2Sub-tutorial ID to navigate to (optional, may be None) |
| --- |
| BaseObjectNot used.S1Tutorial ID to openS2Sub-tutorial ID to navigate to (optional, may be None) |
| S1Tutorial ID to openS2Sub-tutorial ID to navigate to (optional, may be None) |
| S2Sub-tutorial ID to navigate to (optional, may be None) |
