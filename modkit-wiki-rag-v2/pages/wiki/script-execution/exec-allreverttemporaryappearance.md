# Description

Reverts all temporary appearance overrides at once, restoring the character's original appearance for all appearance types (HairColor, SkinTone, MuscleMass, BodyMassRatio).

# Parameters

| ParameterDescriptionBaseObjectThe character whose temporary appearance overrides will all be reverted. |
| --- |
| BaseObjectThe character whose temporary appearance overrides will all be reverted. |

# Examples

| DescriptionBaseObjectCommandReverts all temporary appearance overrides on self.SelfAllRevertTemporaryAppearanceReverts all temporary appearance overrides on target.TargetAllRevertTemporaryAppearance |
