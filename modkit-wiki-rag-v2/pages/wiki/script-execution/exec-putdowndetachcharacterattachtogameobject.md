# Description

Detaches the character currently held in the BaseObject's right hand and attaches that character to the non-base game object resolved from the script context.

# Parameters

| ParameterDescriptionBaseObjectThe character currently holding another character (Self or Target). |
| --- |
| BaseObjectThe character currently holding another character (Self or Target). |
