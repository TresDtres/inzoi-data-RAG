# Description

Removes a time alert entry from the TimeAlertUIHandler for the Self entity.

# Note

BaseObject is not used. This action is always applied to the Self entity.

# Parameters

| ParameterDescriptionBaseObjectNot used. Fixed to Self entity.S1TimeAlertDataId that identifies the alert entry to remove |
| --- |
| BaseObjectNot used. Fixed to Self entity.S1TimeAlertDataId that identifies the alert entry to remove |
| S1TimeAlertDataId that identifies the alert entry to remove |
