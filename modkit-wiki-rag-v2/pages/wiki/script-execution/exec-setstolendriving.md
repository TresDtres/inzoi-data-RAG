# Description

Sets or clears the stolen driving flag on the target vehicle. When enabled, allows a non-owner character to drive the vehicle.

# Parameters

| ParameterDescriptionBaseObjectThe target vehicle entity (Self or Target).F11.0 to enable stolen driving, 0.0 to disable. |
| --- |
| BaseObjectThe target vehicle entity (Self or Target).F11.0 to enable stolen driving, 0.0 to disable. |
| F11.0 to enable stolen driving, 0.0 to disable. |
