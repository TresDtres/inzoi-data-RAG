# Description

Opens the clothing-rack garment ContentPicker for the BaseObject(Self) player. Selecting a garment unlocks it (shown in CAZ) without changing the currently worn outfit.

# Parameters

| ParameterDescriptionBaseObjectSelf (the buyer). S1 = ClothingRackOutfitPool.PoolGroupId filter (empty=all). |
