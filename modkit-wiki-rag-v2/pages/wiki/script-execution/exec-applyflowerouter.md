# Description

Applies a visual outer type to the flower object. The outer type name must match a valid value in the EB1FlowerOuterType enum.

# Parameters

| ParameterDescriptionBaseObjectThe flower entity to apply the outer type to.S1The flower outer type name (must match EB1FlowerOuterType enum value). |
| --- |
| BaseObjectThe flower entity to apply the outer type to.S1The flower outer type name (must match EB1FlowerOuterType enum value). |
| S1The flower outer type name (must match EB1FlowerOuterType enum value). |
