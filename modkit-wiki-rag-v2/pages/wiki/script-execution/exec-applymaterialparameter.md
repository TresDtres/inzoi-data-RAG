# Description

Applies a material parameter mapping to the BaseObject, sending a packet and optionally applying a global material parameter if configured.

# Parameters

| ParameterDescriptionBaseObjectThe entity to which the material parameter is appliedS1MaterialParamMapping ID (from MaterialParamMapping data table) |
| --- |
| BaseObjectThe entity to which the material parameter is appliedS1MaterialParamMapping ID (from MaterialParamMapping data table) |
| S1MaterialParamMapping ID (from MaterialParamMapping data table) |
