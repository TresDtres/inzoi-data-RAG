# Description

Updates the main relationship between Self and Target using the Script update reason. This triggers a recalculation of the main relationship based on current relationship stats. BaseObject is not used; the action always operates on Self and Target from the script context.

# Parameters

| ParameterDescriptionBaseObjectNot used; always updates the main relationship between Self and Target |
| --- |
| BaseObjectNot used; always updates the main relationship between Self and Target |
