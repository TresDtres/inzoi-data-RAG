# Description

Plays an FX effect defined in Fx.json on the specified object. If the FX has a SpawnerId set, the effect is spawned at the world spawner location instead of on the entity.

# Parameters

| ParameterDescriptionBaseObjectThe target object to play the FX effect on.S1The FX ID defined in Fx.json. |
| --- |
| BaseObjectThe target object to play the FX effect on.S1The FX ID defined in Fx.json. |
| S1The FX ID defined in Fx.json. |

# Examples

| DescriptionBaseObjectCommandPlay GrowthStepUp FX on SelfSelfPlayFxPlay LevelUp FX on TargetTargetPlayFx |
| --- |
| Play GrowthStepUp FX on SelfSelfPlayFxPlay LevelUp FX on TargetTargetPlayFx |
| Play LevelUp FX on TargetTargetPlayFx |
