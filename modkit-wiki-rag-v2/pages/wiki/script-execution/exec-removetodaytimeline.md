# Description

Removes all schedules from the BaseObject character's today timeline and deletes any override schedules.

# Parameters

| ParameterDescriptionBaseObjectThe character whose today's timeline schedules will be cleared (Self or Target) |
| --- |
| BaseObjectThe character whose today's timeline schedules will be cleared (Self or Target) |
