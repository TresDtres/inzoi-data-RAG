# Description

Sends a custom mobile message to the BaseObject from a randomly chosen active ResidenceFamily character with whom the BaseObject has no household relationship.

# Parameters

| ParameterDescriptionBaseObjectThe character who receives the text messageS1CustomMobileMessageId (linked to id in CustomMobileMessage.json) |
| --- |
| BaseObjectThe character who receives the text messageS1CustomMobileMessageId (linked to id in CustomMobileMessage.json) |
| S1CustomMobileMessageId (linked to id in CustomMobileMessage.json) |
