# Description

Opens the clothing-rack garment ContentPicker for the BaseObject(Self) player. Selecting a garment unlocks it and immediately swaps that part onto the currently worn outfit (other parts unchanged).

| ParameterDescriptionBaseObjectSelf (the buyer). S1 = ClothingRackOutfitPool.PoolGroupId filter (empty=all). |
