# Description

Blocks the non-BaseObject's phone number in the BaseObject's contact list. When blocked, neither party can send or receive messages with each other.

# Parameters

| ParameterDescriptionBaseObjectThe entity that will block the phone number |
| --- |
| BaseObjectThe entity that will block the phone number |
