# Description

Stops a controllable 2D sound for the target entity. The stop request is sent regardless of possession so pending playback can also be cancelled.

# Parameters

| ParameterDescriptionBaseObjectThe target object whose controllable sound is stopped.S1The SoundId defined in the AudioResources table. |
| --- |
| BaseObjectThe target object whose controllable sound is stopped.S1The SoundId defined in the AudioResources table. |
| S1The SoundId defined in the AudioResources table. |
