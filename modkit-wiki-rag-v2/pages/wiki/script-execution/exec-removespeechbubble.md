# Description

Removes the speech bubble currently displayed on the specified BaseObject, identified by the SpeechBubble ID provided in S1.

# Parameters

| ParameterDescriptionBaseObjectThe entity from which the speech bubble will be removed.S1The SpeechBubble ID to remove. |
| --- |
| BaseObjectThe entity from which the speech bubble will be removed.S1The SpeechBubble ID to remove. |
| S1The SpeechBubble ID to remove. |
