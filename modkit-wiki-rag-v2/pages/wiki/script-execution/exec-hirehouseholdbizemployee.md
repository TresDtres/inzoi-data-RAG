# Description

Hires the BaseObject character as an employee of the HouseholdBiz found at the BaseObject's current site. The NonBaseObject must be the HouseholdBiz manager; if not, this Execute does nothing. The employee is hired with a default role, Normal salary level, and Default work outfit.

# Parameters

| ParameterDescriptionBaseObjectThe character (candidate) to be hired; must be at a site linked to a HouseholdBiz |
| --- |
| BaseObjectThe character (candidate) to be hired; must be at a site linked to a HouseholdBiz |
