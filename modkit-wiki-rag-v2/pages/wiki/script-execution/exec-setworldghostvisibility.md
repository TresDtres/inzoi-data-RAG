# Description

Makes all ghost Zois visible in the map and enables living Zois to interact with ghost Zois, or hides all ghosts and disables interaction depending on F1.

# Parameters

| ParameterDescriptionBaseObjectNot usedS1Reason value used for hiding charactersS2Reason value required for setting ghost interaction availabilityF10: Disables interaction and hides all ghosts. 1: Enables interaction and shows all ghosts. |
| --- |
| BaseObjectNot usedS1Reason value used for hiding charactersS2Reason value required for setting ghost interaction availabilityF10: Disables interaction and hides all ghosts. 1: Enables interaction and shows all ghosts. |
| S1Reason value used for hiding charactersS2Reason value required for setting ghost interaction availabilityF10: Disables interaction and hides all ghosts. 1: Enables interaction and shows all ghosts. |
| S2Reason value required for setting ghost interaction availabilityF10: Disables interaction and hides all ghosts. 1: Enables interaction and shows all ghosts. |
| F10: Disables interaction and hides all ghosts. 1: Enables interaction and shows all ghosts. |
