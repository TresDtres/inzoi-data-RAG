# Description

Resets the crime score of the BaseObject character. If S1 specifies a Crime ID, resets only that crime's score. If S1 is omitted (None), resets all crime scores.

# Parameters

| ParameterDescriptionBaseObjectThe character whose crime score will be resetS1Crime ID to reset. If omitted (None), resets all crime scores. |
| --- |
| BaseObjectThe character whose crime score will be resetS1Crime ID to reset. If omitted (None), resets all crime scores. |
| S1Crime ID to reset. If omitted (None), resets all crime scores. |
