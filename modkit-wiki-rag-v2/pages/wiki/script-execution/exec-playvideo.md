# Description

Plays a UI/Media video defined in DA_VideoPlayer, centered on the specified BaseObject character. This is for UI/Media videos and not Level Sequences.

# Parameters

| ParameterDescriptionBaseObjectThe character that the video playback is centered on.S1The video ID defined in DA_VideoPlayer. |
| --- |
| BaseObjectThe character that the video playback is centered on.S1The video ID defined in DA_VideoPlayer. |
| S1The video ID defined in DA_VideoPlayer. |
