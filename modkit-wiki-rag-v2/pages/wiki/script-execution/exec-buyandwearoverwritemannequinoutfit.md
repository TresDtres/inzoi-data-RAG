# Description

Registers the Target mannequin's outfit into the Self character's CategorizedStyles and immediately changes the character's active outfit to that category. If the category is full, overwrites the representative slot instead of failing.

| ParameterDescriptionBaseObjectSelf (character buying and wearing the outfit). |
