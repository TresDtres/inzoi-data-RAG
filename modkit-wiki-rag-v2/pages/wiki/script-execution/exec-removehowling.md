# Description

Deactivates (removes) a previously activated howling effect from the entity specified by BaseObject. If the specified howling is not currently active, the call is safely ignored.

# Parameters

| ParameterDescriptionBaseObjectThe entity to deactivate the howling effect from (Self or Target).S1Howling DtId to deactivate. |
| --- |
| BaseObjectThe entity to deactivate the howling effect from (Self or Target).S1Howling DtId to deactivate. |
| S1Howling DtId to deactivate. |
