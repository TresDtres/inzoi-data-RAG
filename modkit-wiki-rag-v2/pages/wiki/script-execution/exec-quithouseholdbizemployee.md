# Description

Processes a voluntary resignation for the BaseObject employee from their employed HouseholdBiz. Unlike FireHouseholdBizEmployee, this function does not require a manager check and resolves the HouseholdBiz from the character's employment profile rather than their current site location.

# Parameters

| ParameterDescriptionBaseObjectThe character who will resign; must be currently employed at a HouseholdBiz |
| --- |
| BaseObjectThe character who will resign; must be currently employed at a HouseholdBiz |
