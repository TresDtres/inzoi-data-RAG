# Description

Shows a transient plumbob icon above the specified object (e.g. a coop-eat indicator). The plumbob is automatically hidden again after a fixed display time (see UB1RelationStateFxComponent).

# Parameters

| ParameterDescriptionBaseObjectThe target object to show the transient plumbob on.S1The PlumbobFx Id defined in PlumbobFx.json. |
| --- |
| BaseObjectThe target object to show the transient plumbob on.S1The PlumbobFx Id defined in PlumbobFx.json. |
| S1The PlumbobFx Id defined in PlumbobFx.json. |
