# Description

BL-59528: Resets the BaseObject mannequin's body-gender school uniform to the designer's initial (DataAsset) uniform, overwriting any current designation, and re-dresses enrolled students. The mannequin display is refreshed to match; if the DataAsset has no default for that gender the uniform is cleared and the mannequin reverts to its placed default.
