# Description

[Deprecated] (BL-57370 follow-up) No longer used. Categories are passed directly through the S2 parameter of SelectOrRandomSalonHair, and ApplyFail derives the same-category fallback from the picked PoolId. It does not store SubCategory in a component. Kept registered for already submitted data, but acts as a no-op. Do not use in new data.
