# Description

Changes the channel of the BaseObject to the specified channel. The instigator is set to the non-BaseObject entity. Channel is used to categorize object visual variations (e.g., holiday themes, seasonal decorations).

# Parameters

| ParameterDescriptionBaseObjectTarget GameObject to change the channelS1Channel ID to change to |
| --- |
| BaseObjectTarget GameObject to change the channelS1Channel ID to change to |
| S1Channel ID to change to |
