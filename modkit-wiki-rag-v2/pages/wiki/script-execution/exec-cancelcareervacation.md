# Description

Cancels a previously applied career vacation. Restores vacation days (PaidVacation only) and rebuilds the weekly commute schedule. Days already consumed (past start time) are not restored.

# Parameters

| ParameterDescriptionBaseObjectThe character canceling vacation.S1EB1CareerType; defaults to Business if omitted. |
| --- |
| BaseObjectThe character canceling vacation.S1EB1CareerType; defaults to Business if omitted. |
| S1EB1CareerType; defaults to Business if omitted. |
