# Description

Adds the specified modifier to all child objects currently stored in the inventory of the base entity.

# Parameters

| ParameterDescriptionBaseObjectThe inventory owner whose child objects receive the modifier.S1The modifier ID to add (must not be None). |
| --- |
| BaseObjectThe inventory owner whose child objects receive the modifier.S1The modifier ID to add (must not be None). |
| S1The modifier ID to add (must not be None). |
