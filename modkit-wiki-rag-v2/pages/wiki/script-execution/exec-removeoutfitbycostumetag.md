# Description

Removes all outfits from the character that carry the specified CostumeTag.

# Parameters

| ParameterDescriptionBaseObjectThe character whose outfits will be modified (Self or Target).S1CostumeTag identifier; all outfits with this tag will be removed. |

| BaseObjectThe character whose outfits will be modified (Self or Target).S1CostumeTag identifier; all outfits with this tag will be removed. |
