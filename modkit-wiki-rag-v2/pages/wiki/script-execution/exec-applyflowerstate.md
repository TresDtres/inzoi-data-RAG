# Description

Applies a new state to the flower object (e.g., Blooming, Wilted). The state name must match a valid value in the EB1FlowerStateType enum.

# Parameters

| ParameterDescriptionBaseObjectThe flower entity to apply the state to.S1The flower state type name (must match EB1FlowerStateType enum value). |
| --- |
| BaseObjectThe flower entity to apply the state to.S1The flower state type name (must match EB1FlowerStateType enum value). |
| S1The flower state type name (must match EB1FlowerStateType enum value). |
