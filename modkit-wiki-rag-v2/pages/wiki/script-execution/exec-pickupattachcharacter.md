# Description

Makes the Self character pick up and attach the Target character to Self's right hand. Self and Target are resolved directly from the script context. No script parameters are used.

# Parameters

| ParameterDescriptionBaseObjectNot used. Self and Target are resolved from the script context. |
| --- |
| BaseObjectNot used. Self and Target are resolved from the script context. |
