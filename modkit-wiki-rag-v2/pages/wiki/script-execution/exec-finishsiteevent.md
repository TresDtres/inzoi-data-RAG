# Description

Forcibly ends the site event that is currently in progress for the entity resolved from BaseObject. If no site event is active for that entity, the script does nothing.

# Parameters

| ParameterDescriptionBaseObjectThe entity whose currently running site event will be forcibly ended. |
| --- |
| BaseObjectThe entity whose currently running site event will be forcibly ended. |

# Examples

| DescriptionBaseObjectCommandForcibly finish the current site event for SelfSelfFinishSiteEventForcibly finish the current site event for TargetTargetFinishSiteEvent |
| --- |
| Forcibly finish the current site event for SelfSelfFinishSiteEventForcibly finish the current site event for TargetTargetFinishSiteEvent |
| Forcibly finish the current site event for TargetTargetFinishSiteEvent |
