# Description

Sends S_StartLookAtLoc packet to the BaseObject character to start looking at a location. The world location is resolved from UB1MapPositionDataAsset using S1 as the position key and the current city id as the inner key.

# Parameters

| ParameterDescriptionBaseObjectThe character that will start looking at the location.S1Position id (outer key of UB1MapPositionDataAsset.Position). |
| --- |
| BaseObjectThe character that will start looking at the location.S1Position id (outer key of UB1MapPositionDataAsset.Position). |
| S1Position id (outer key of UB1MapPositionDataAsset.Position). |
