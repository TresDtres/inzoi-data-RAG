# Description

Cancels the active freelance order for the BaseObject character. All associated quests will be removed, NPCs will be recalled, and the order will be marked as cancelled. Trust penalties may apply based on the cancellation timing.

# Parameters

| ParameterDescriptionBaseObjectThe character entity whose active freelance order to cancel. |
| --- |
| BaseObjectThe character entity whose active freelance order to cancel. |
