# Filter Command Finder

Every TargetFilter on one page. A Condition decides *whether* a script runs; a Filter decides *what it runs against*.

How to use this

- **Search** matches the command name and its description at once. Multiple words are combined with AND.
- **Topic** groups filters by what they search for — a posture slot, an object, a character, a site.
- Every filter takes `InContext`, `InFilter` and `OutResult`. Only the `InFilter` fields differ, so those are what the **Uses** column lists.

## Reading a Filter row

Each command page lists exactly which `InFilter` fields it reads and what values they accept.
