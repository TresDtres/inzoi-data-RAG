# Object Sound

Sounds attached to objects. Sort by clicking a header, search by name, or filter by category.

How to read this

Each row is a sound set. When its name matches an object, the object's thumbnail is shown too.

`Sounds` is how many separate sounds the set holds — opening and closing a door are different entries.
