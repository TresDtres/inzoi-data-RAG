# Raw Resources

The FBX and texture sources that ship with the ModKit. Open these in Maya or Blender when you want to start from an existing asset.

Where the files are

| GroupFolderObjects`[installation path]\inZOIModKit\Data\RawResources\Objects`Hair · Sets · Skins · Stocking`[installation path]\inZOIModKit\Data\RawResources` |
| --- |
| Objects`[installation path]\inZOIModKit\Data\RawResources\Objects`Hair · Sets · Skins · Stocking`[installation path]\inZOIModKit\Data\RawResources` |
| Hair · Sets · Skins · Stocking`[installation path]\inZOIModKit\Data\RawResources` |

The names listed here are the file names on disk.

## Naming

CAZ file names follow one convention:

| PrefixMeaning`W_`Female`M_`Male`_Child_`Child (absent on adult items)`B_` · `L_` · `M_` · `S_` · `SS_`Bangs · Long · Medium · Short · Super short |
| --- |
| `W_`Female`M_`Male`_Child_`Child (absent on adult items)`B_` · `L_` · `M_` · `S_` · `SS_`Bangs · Long · Medium · Short · Super short |
| `M_`Male`_Child_`Child (absent on adult items)`B_` · `L_` · `M_` · `S_` · `SS_`Bangs · Long · Medium · Short · Super short |
| `_Child_`Child (absent on adult items)`B_` · `L_` · `M_` · `S_` · `SS_`Bangs · Long · Medium · Short · Super short |
| `B_` · `L_` · `M_` · `S_` · `SS_`Bangs · Long · Medium · Short · Super short |

Object names are `[ItemType][Version]` — for example `Bed01`, `Lighting02_v17`.
