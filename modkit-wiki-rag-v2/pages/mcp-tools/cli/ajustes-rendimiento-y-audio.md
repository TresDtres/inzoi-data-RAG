| graphics_set_option | `graphics.set_option(Option, Value)` | Fija una opcion grafica individual. | [CLI: graphics.set_option] Set an individual graphics option. Quality values are typically 0-4 (0=lowest, 4=highest). | no publicitado — completar tras prueba en vivo | activo |
| graphics_set_preset | `graphics.set_preset(Preset)` | Fija el preset de calidad grafica (minimum, verylow, low, normal...). | [CLI: graphics.set_preset] Set graphics quality preset. | graphics_get_settings | `graphics.get_settings()` | Devuelve los ajustes graficos: preset, resolucion, calidad... | [CLI: graphics.get_settings] Returns current graphics settings including preset, resolution, quality levels, FPS limit, and upscaling options as JSON. | no publicitado — completar tras prueba en vivo | consultivo |

| gameplay_set_language | `gameplay.set_language(Value)` | Cambia el idioma del juego (nombres de cultura de Unreal, p. ej. ko, en). | [CLI: gameplay.set_language] Change the game display language. Call gameplay.list_languages to see the exact set. | no publicitado — completar tras prueba en vivo | activo |
| gameplay_set_autosave | `gameplay.set_autosave(Enable, Interval)` | Activa o desactiva el autoguardado y fija su intervalo. | [CLI: gameplay.set_autosave] Enable/disable autosave and set the interval. | gameplay_get_settings | `gameplay.get_settings()` | Devuelve ajustes de gameplay: idioma, tamano de UI, nivel de autonomia, autosave... | [CLI: gameplay.get_settings] Returns gameplay settings: language, UI size, autonomy level, autosave config, character name format. | wiki: Returns a JSON object with the following fields: | consultivo |
