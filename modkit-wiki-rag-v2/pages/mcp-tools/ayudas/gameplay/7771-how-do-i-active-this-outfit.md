# How do i active this outfit?

**Sintoma:** I can’t use this at all. It doesn’t appear on the dress list either. 20251211132019_1 320×341 28.9 KB

**Causa:** desconocida

**Solucion:** This outfit seems to be downloadable in Canvas. It’s been created by user Tornado and here’s the direct link to the canvas page: inZOI Canvas After downloading it in-game or via the official canvas page, you go into CAZ (Create-A-Zoi). This specific download is only available through the category “ZOI-Presets”, also only when creating a new family / save file. If you want a workaround for an existing save file, I’d recommend doing this: Click “new game” Select the life stage “kid” Go to “ZOI-Presets” (the first one on the bottom left) Then click on the downloaded Preset on the right hand side (just like in the screenshot you uploaded) Then go to the “Outfit” category on the bottom There you click “save” on the ride hand side, first icon in the clothing icons Afterwards it should look like the screenshot I took for you here: inZOI 11.12.2025 23_26_18 748×499 63.7 KB → Then you can go back to your already existing save, load it and use this outfit whenever you desire. Hope this helps!
