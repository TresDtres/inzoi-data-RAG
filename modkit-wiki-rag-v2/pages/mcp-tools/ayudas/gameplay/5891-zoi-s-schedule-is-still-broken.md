# Zoi’s schedule is still broken

**Sintoma:** My zois schedule is still broken after the v0.3.6 update. I played an additional 3 in game weeks and their work/school did not return to their schedule. This issue affects my teen and YA zois in my household. They only work/school 2 days a week now. The adult’s schedule is fine. Also, this same zoi had 8 messages from friends that says they’re out their league and I respond with let’s meet up. I get the message that it’s added to the calendar but it’s not. I’m not sure if it’s because I’m in Cahaya that it doesn’t work and the lot that the meet up is supposed to occur on, doesn’t exist so it never adds to schedule. This happens in all my households for this particular issue. Please just add

**Causa:** desconocida

**Solucion:** Hi everyone ( @here ), When Smart Zoi is enabled, existing schedules may be overwritten by schedules generated by the Smart Zoi. This issue has been fixed in v0.4.0
