# Romantic relationships incompatible with established identity

**Sintoma:** My Sim has a heterosexual identity set and I had already planned a husband for her, but while I was playing another family, she generated a romance that doesn’t match the settings and now it’s bothering me by generating desires. I think I know how to fix it with code but it’s annoying. Why have the option to set identity then?

**Causa:** desconocida

**Solucion:** Thank you for reporting this. Can you please make sure that none of the removed hair and clothing mods are still in your game folders? They can cause weird behavior in game. crashing when coming out of mods menu Documents\inZOI\Mods There will be a numbered folder in this folder and all of your mods (from in-game downloading) are in there except ones that you may have manually installed which will be: C:\Program Files (x86)\Steam\steamapps\common\inZOI\BlueClient\Content\Paks~mods You can pull the folders (or files) out from there. Unfortunately, we’ve had quite a few of similar reports from other users. The best workaround for the bug is to go into CAZ (Create-A-Zoi at the bottom right corner, next to build mode) and set their preferences to the ones you’d like them to have
