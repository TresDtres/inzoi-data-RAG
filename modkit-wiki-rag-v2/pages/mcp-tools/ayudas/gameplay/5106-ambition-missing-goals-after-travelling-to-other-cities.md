# Ambition missing goals after travelling to other cities

**Sintoma:** start an ambition (ex: Tranquil Mind). Complete a bit of it. Travel to a different city. Complete first page of ambition while in this new city. Travel home. Ambition no longer shows any goals I can send if I get the email. Tested with multiple save files, with and without mods. Ambition goals go missing after travelling between cities. I’ve seen it happen with the Master Chef, Tranquil Mind, Philanthropist and Luxury Mansion aspirations. I didn’t try any others but I’m convinced it’s the same behavior for all ambitions. Note when you return to the city where you last completed a goal from the ambition, it shows again but it should always be there regardless of which city you are in. image 7

**Causa:** desconocida
