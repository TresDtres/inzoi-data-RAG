# Characters clip into each other during kiss animation near school desks

**Sintoma:** The only mods I use are cosmetic mods. I tested the game with all mods disabled, and the issue still occurs. Go to a school. Place two Zois next to a school desk. Select the “Kiss” interaction. Observe the animation. When two Zois perform the Kiss interaction near a school desk, the animation does not play correctly. Instead of repositioning themselves, both Zois clip into each other and into the desk. The issue appears to occur only with school desks. The same interaction works normally near regular tables. I don’t think a save file is necessary in this case, as the issue doesn’t seem to be tied to a specific save. I’ve seen other players mention the same bug on other platforms as well. 245
