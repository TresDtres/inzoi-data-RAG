# Some skills progress extremely slow - the Zoi would die from old age before reaching level 10

**Sintoma:** For some skills the progression is extremely slow. It is completely Ok that it takes a while to get to a high skill level with all the benefits which it brings but for some skills it feels extreme. E.g. for painting, gardening, fitness, performing you will need time but will be able to reach level 10 of the skill if your Zoi is focused on this. But for skills like cooking or programming or instruments it is nearly impossible to achieve this within the lifetime of a Zoi, even less if you play with the currently intended 48 minutes day. This feels really wrong. The Zoi needs e.g. 4 hours to make a game mod using his programming skil and to move from level 1 to level 2 of the programming skill

**Causa:** desconocida

**Solucion:** Hello everyone ( @here ), This issue was fixed in v0.5.0 . Skill Balance Improvements We have improved issues where certain skills were difficult or took too long to level up. Skill experience gained from interactions and other activities has been increased, making it easier to level up your skills than before
