# How can I stop this from popping up every time I open inZOI?

**Sintoma:** For some reason I received Automatic MODs, I didn’t download but the game wants me to have them for reasons unknown, most of these installed what I clicked the button, this Mod is broken or whatever and fails to install, so I turned MODs OFF and yet this still pops up to get me to try to install it every time I open the game, and the worst part is that it’s a MOD that I don’t even want, but if installing it would stop it from popping up I’d install it to get rid of the annoyance, but it won’t stop, PLEASE TAKE THIS OUT OF MY GAME SOON. MOD Update FAILURE 1920×1080 243 KB

**Causa:** desconocida

**Solucion:**

1. This is how I would personally do it: With the game closed, copy the entire Documents\inZOI\Mods folder to another location as a backup
2. Start inZOI and open the installed Mods list
3. Choose Delete rather than Disable
4. Close the game completely
5. Check the Mods folder for any leftover files or numbered folders and remove them if necessary
