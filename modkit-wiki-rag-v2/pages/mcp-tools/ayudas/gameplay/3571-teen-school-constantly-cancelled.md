# Teen School Constantly Cancelled

**Sintoma:** OS - Windows 11 Pro, Version 10.0.26100 Driver - Nvidia Game Ready Driver - 581.08 CPU - AMD Ryzen 7 5800X3D 8-Core Processor RAM - 64.0 GB Video Card - NVIDIA GeForce RTX 5070 (SmartZoi is turned ON, Settings are Ultra + Realistic Shadows/Lighting, World Map: Cahaya) Not sure if this is a feature or a bug, but I can’t find any consistency in it. I have a household with 2 teens. For the 3ish weeks (in-game) I’ve been playing the family, Teen 1 (Male) has almost constantly had his school canceled/replaced by other events, while Teen 2 (Female) has been able to go more often, but still has had one or two days a week cancelled. Sometimes it changes the day of, sometimes it just never schedules

**Causa:** desconocida

**Solucion:** Hi everyone ( @here )! Sorry for the inconvenience this issue has caused so far. The following issues have been resolved with v0.3.6 Fixed an issue in Cahaya where Zois would not go to school if the commute time and school start time did not align. → Please note that when continuing from affected save files, this fix will take effect up to 7 in-game days later. Fixed an intermittent issue where events were being canceled in the Schedule Editor. Fixed an issue where a Zoi would automatically quit their rabbit hole job when a “Get Married” conversation was initiated. Since these issues have been resolved, I’ll close this post. If you still encounter the same problem after updating, please let us know by creating a new post. Thank you for being part of inZOI!
