# No Skill Progression with Swim Lessons

**Sintoma:** N/A (not a hardware issue) Sign up a Zoi up for Swim Lessons via the Computer Attend Swim Lessons on in-game Thursdays or Saturdays Wait until after the lesson, then check the Zoi’s Swimming Skill progress. The skill level stays the same. Attending Swim Lessons via the computer does not increase Swimming Skill

**Causa:** desconocida

**Solucion:** Hi @LazyTaco Thanks for bringing this up. Just to clarify—it’s not a bug, it’s how it’s meant to work. When you sign up for Swim Lessons on the computer, your Zoi gets a Rabbit Hole schedule. Inside that Rabbit Hole, the skill only goes up if the interaction succeeds, not just for attending. So taking the class doesn’t always guarantee progress, but depending on how it goes, your Zoi’s Swimming Skill can improve. Hope that clears it up!
