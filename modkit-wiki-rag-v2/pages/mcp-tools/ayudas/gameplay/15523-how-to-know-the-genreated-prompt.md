# How to know the genreated prompt?

**Sintoma:** Ok so i want to know How to see the Prompt you made before, becuase i make a random prompt and i like what the Ai do. so the next day i play with it, but i want to change color but forget the prompt

**Causa:** desconocida

**Solucion:** Navigate to the path C:\Users\YOUR PROFILE NAME\Documents\inZOI\Creations\MyTextures\ (it’s possible that on Windows 11, the path might be slightly different — I’m describing it based on Windows 10) You’ll find folders there that you can sort by creation date to find your specific texture. In the folder, besides the albedo.jpg file that contains the texture itself, there will also be a meta.json file. Open it with Notepad. There will be a “Prompt” section, and in it you’ll see a description of the request you used to create it. Just to be safe, I’ll mention that this will only work for your own textures — in downloaded ones, this section will be empty, which is normal
