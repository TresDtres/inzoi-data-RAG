# Is anyone else having a problem with the resort stairs?

**Sintoma:** The two Zoi households that are living at the resorts can’t use their second floors. They can’t seem to go up the stairs and that’s where the bedrooms are, so they’re having a difficult time of it. I’ve tried fixing it and I can’t. I’ve tried resetting the properties and that doesn’t work. Is anyone else having this problem? I’d like to resolve it before it gets worse for the families. They’re already unhappy

**Causa:** desconocida

**Solucion:** Hi everyone ( @here ), Zois may intermittently be unable to move between floors using certain staircases. Please note that when continuing from an already affected save file, the issue may still persist. This issue was fixed in v0.4.0
