# Stuck task if completed before it started

**Sintoma:** Have your business be at 1 star or hire 1 employee already before the task to do that pops up. 20251223-213508.zip (5.8 MB) When you play the questline for the new My Business Feature called ‘Respectable Boss’ you will eventually get quests like ‘Hire your first employee’ or ‘Business Value 1 Star: Establish a store with just a sign’. If you have already done these things before the task pops up, it will not auto-complete and you will be stuck on this task forever. It will look like this: image 386×503 31.7 KB My business value was already one star before I got the task: image 687×199 25.2 KB I thought maybe you had to purchase a sign but that didn’t help either: image 1338×922 311 KB

**Causa:** desconocida

**Solucion:** Hi everyone ( @here ), This issue was fixed through v0.5.3 update
