# Unable to gain money with programmed software

**Sintoma:** Program something using an old computer, after finishing it (whatever it’s made in a single time or not), trying to sell it. Send me a link please When my character program something, it seem to always be, regardless of the quality, a 1 $ project. I tries multiple software, but each time it’s the same thing. Also, it never gives me a single $ in my account. Also, idk if it’s normal, but I reached programming level 8 in like, 4 days (doing others actions during the day) , which it seem to be a small amount of time ? image 962×814 70.9 KB image 770×479 83.1 KB

**Causa:** desconocida

**Solucion:** Hello and welcome to the forum​ . About the payment: The payment for programs, books and the like works a bit differently than normal “selling”. You get royalties instead which means you’ll get a fixed amount of money after a certain period of time(I think it was weekly). You don’t get the money instantly, but periodically through royalties. If you don’t receive any royalties in a span of a week, then there might be a bug at hand. Maybe you can check if you get some payment after a couple of days? If not, then there is probably an actual bug causing the issue. As for the amount of money received, moodlets actually influence the end product quite a bit. If your Zoi is in a bad mood, it lowers the quality of the item you create. That goes pretty much for everything you craft. So even if you have a relatively high level, the quality can still be mediocre. For programming, I think “Focused” was the best moodlet. Also, if you are per example Level 5 in programming and try making a Level 5 program, the result can still be lower since it is a “more difficult” item to create and you only have the “minimum level” required for it. Chances are also a bit better if you per example craft a Leve
