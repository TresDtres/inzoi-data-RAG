# Scooters can only be driven by males in mixed pairs

**Sintoma:** When a male owns a scooter, there’s no problem. I understand that maybe it’s more practical to have the heavier person in front or something, but 1) this is definitely not a designed behaviour, the error message doesn’t explain it 2) since vehicules can’t be shared, that means that both Zois need to have a scooter, even if it’s the woman who needs it 90% of the time

**Causa:** desconocida

**Solucion:** Hi everyone ( @here ), When a male Zoi rides on the backseat of a scooter, the animation may appear incorrect. This issue was fixed in v0.4.0

**EN:** Scooters can only be driven by males in mixed pairs
