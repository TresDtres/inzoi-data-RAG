# Frequent “The power cable is disconnected.” messages in macOS version

**Sintoma:** Using battery will limit performance and drop your framerate. If you want a smooth gameplay experience, connect the cable!” This is very annoying as it can happen every 15~30 seconds and there appears to be no way of disabling it. Although performance may not be as good I just want to play my game away from the wall Is there a way to reduce these or make it into a toggle? Thanks!! Untitled 3024×1964 716 KB

**Causa:** desconocida

**Solucion:** Hi @nadozza , We’ve adjusted warning message frequency with v0.3.5 . (Mac Only) Adjusted warning message frequency when MacBook power cable is disconnected. ※ [inZOI Team’s Comment] This message was added to inform players of potential performance degradation when the power cable is not connected. However, since it was confirmed to appear too frequently, the interval has been adjusted to display only once every three hours
