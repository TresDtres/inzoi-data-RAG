# Toilet cleaning

**Sintoma:** I don’t know Instruction: 2025.11.07 The toilet was dirty so I tried to clean it by clicking on the toilet, but the clean option doesn’t appear. Is this a bug??? If it’s not a bug, what should I do???

**Causa:** desconocida

**Solucion:** Hi @sally1119032 ! Just to clarify, there isn’t a cleaning interaction directly on the toilet. You can find the Clean option by clicking the floor near it instead. When the cleaning starts, nearby objects will also be cleaned automatically, so please keep that in mind during gameplay. Since this isn’t a bug, I’ll be closing this topic.
