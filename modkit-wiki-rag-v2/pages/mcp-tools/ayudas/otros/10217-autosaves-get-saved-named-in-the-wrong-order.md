# Autosaves get saved/named in the wrong order

**Sintoma:** Autosave_1 should be the first and _3 the last, neither is image 1920×1080 271 KB

**Causa:** desconocida

**Solucion:** That’s normal. When it saves, it will overwrite in sequence. In your example, it already saved over #1 and #2 (Since #1 is older than 2 it sits below) And #3 will get overwritten on the next autosave (or if you customzoi/edit appearance). It is because they are sorted by last modified date
