# Romance Interactions Missing or Always Failing

**Sintoma:** OS - Windows 11 Pro, Version 10.0.26100 Driver - Nvidia Game Ready Driver - 581.08 CPU - AMD Ryzen 7 5800X3D 8-Core Processor RAM - 64.0 GB Video Card - NVIDIA GeForce RTX 5070 (SmartZoi is turned ON, Settings are Ultra + Realistic Shadows/Lighting, World Map was Cahaya) Started a new game with a married couple, but the married couple didn’t have advanced relationship options such as kiss or suggest a baby. This couple were adults and were True Loves and Best Friends. To troubleshoot, I started a new game with single characters and tried to get them to flirt. No flirting options worked, and the Charm skill did not initiate. Furthermore, there were no books for Charm or Charm-based actions. T

**Causa:** desconocida

**Solucion:**

1. Basically, when you create a zoi their gender and attraction gets set randomly regardless of their appearance
2. So you might make a female zoi, but her gender might be set to male
