# Length of each life stage

**Sintoma:** Does anyone have a list of the default length (in days) for each life stage? It would make it much easier to calculate how much you need to adjust them by if you want them shorter or longer

**Causa:** desconocida

**Solucion:** Second column (after 0.2.0) Also in number of days : Newborn(3), Toddler(6), Child(10), Adolescent(5), Teenager(15), Young Adult(30), Adult(10), Middle-Age(10) and Senior(10)
