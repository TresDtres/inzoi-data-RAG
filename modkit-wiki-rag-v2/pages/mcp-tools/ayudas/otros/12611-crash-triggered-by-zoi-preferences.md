# Crash triggered by Zoi preferences

**Sintoma:** The game consistently crashes when Zois perform interactions linked to their active preferences (marked with a star ) . Reproduction findings: Zoi with Yoga preference ( ) : Using yoga mat → immediate crash Watching yoga-related TV program → crash Zoi with Cleaning preference ( ) : Performing cleaning interaction → crash Zoi without relevant preference: Same interactions function normally without issues Key observations: The issue is not tied to specific objects (yoga mat, TV, cleaning actions all tested) The crash only occurs when the preference-enhanced interaction variant ( ) is triggered Removing the preference from the Zoi completely resolves the issue All crash logs show the same type

**Causa:** desconocida

**Solucion:** UPDATE: After updating to version 0.8.3, I tried running the game without mods, and everything worked as expected. However, as soon as I added the mods from the “Paks/~mods” folder, the game crashed again with the same pattern. After several attempts, I managed to find the conflicting mod and get the game working correctly. I don’t understand the connection between that mod (a mod that removes visual effects) and a Zoi’s favorite actions, but for some reason, I can now perform their favorite actions without the game crashing, so I can say the problem is solved. Sorry for the inconvenience
