# Scooters

**Sintoma:** Mods ( active) Hair and clothes Details The option to drive here or use auto drive does not work with scooters

**Causa:** desconocida

**Solucion:** Hi @Robert , Currently, scooters can only be used with manual driving. Please try enabling the “Enable Manual Driving of Mount” option under Game Options > Gameplay > Vehicle Ride (Experimental Feature) . image 1920×1027 42.7 KB Once it’s turned On , you should be able to manually control scooters using the WASD keys after mounting them
