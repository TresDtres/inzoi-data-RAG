# Canvas：No internet connection？！！！

**Sintoma:** Canvas cannot be opened and prompts “no internet connection,” MOD browser and download features work normally. It has been in this state since last night. Canvas is inaccessible for both browsing and uploading. Screen Shot 2025-11-03 at 01.16.33.900 AM 1920×1080 257 KB

**Causa:** desconocida

**Solucion:** After several days of independent research, I finally identified the cause: it was DNS pollution, which non-technical users might find difficult to diagnose. In any case, it’s resolved now. I hope this can serve as a reference for players encountering similar issues. If you suddenly cannot upload to Canvas, try changing your DNS settings and restarting your router – this should restore functionality. Screen Shot 2025-11-04 at 04.05.02.880 PM 1920×1080 264 KB
