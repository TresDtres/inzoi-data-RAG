# Items cannot be appended from appended items after new update

**Sintoma:** Modkit Version : Latest. Open modkit, create new project or open a previous project, try to append a new item from an item that was previously appended. Hi there! Before the latest modkit update, creators were able to “append new item” from items that had been previously appended. This was useful because you could replicate the item with the same data and just maybe change one set of data to make variants, instead of appending a whole new item and then having to write and select all the data again. After the modkit update, this is no longer possible. When you append a new item from an already appended item, it just never appends, it kind of disappears? You have to append from zero which is a

**Causa:** desconocida

**Solucion:** Hi @itsmechiie7 , This known issue has been resolved in the latest update (see Patch Notes ). Fixed an issue where the “Append new item” function did not work with newly added data If you’re still experiencing this problem after updating, please let us know in a new thread
