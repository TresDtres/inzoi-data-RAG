# Halloween Content?

**Sintoma:** Don’t really know where to put this, but since buying the game I see a Halloween splash screen every time I launch, but all the Halloween content has been removed from Canvas. You can still do Halloween things in game (candy bucket, spooky laugh, etc), but none of the content seems to be available. If you download Zois wearing the outfit from canvas, they’ll just appear as in their undies in the creator. It’s pretty confusing and frustrating to be honest. Is there something I’m missing here?

**Causa:** desconocida

**Solucion:**

1. If it’s an official Halloween outfit provided by inZOI , you can download it directly from the Creations section in the Palette
2. In this case, you’ll need to run a mod sync for the outfit to appear correctly
3. ※ For reference, during the sync process, you’ll be asked whether you want to delete or keep the mod
