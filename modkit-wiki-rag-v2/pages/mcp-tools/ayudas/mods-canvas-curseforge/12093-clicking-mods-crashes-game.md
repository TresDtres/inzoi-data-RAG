# Clicking ‘Mods’ crashes game

**Sintoma:** Processor: AMD Ryzen 5 5600H with Radeon Graphics Installed RAM: 16.0 GB (15.9 GB usable) Clicking “Mods” on the main page crashes the game

**Causa:** desconocida

**Solucion:** I was able to “fix” the problem by: Delete ALL the contents of the …/Documents/inZOI/Mods/ and …/Documents/inZOI/ModSave/ folders Once the game is loaded go to Mods and unsubscribe to all the mods. Subscribe to the mods again
