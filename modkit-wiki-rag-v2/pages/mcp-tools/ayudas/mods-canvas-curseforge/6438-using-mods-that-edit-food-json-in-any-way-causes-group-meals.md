# Using mods that edit Food.json in any way causes group meals to be ‘served’ as empty plates

**Sintoma:** Create and/or install a mod that edits Food.json. Cook and serve a group meal in game. The meal will be served as an empty dish. I have encountered this bug with any individual mod that edits Food.json. Removing all mods that edit this json file fixes the issue. I believe this is an issue similar to the ‘Refuse Conversation’ bug from 0.3.0

**Causa:** desconocida

**Solucion:** HI everyone ( @here )! When using mods that modify the Food.json file, some food items may appear as empty plates. The issue was fixed in v0.4.3
