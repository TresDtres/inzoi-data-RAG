# Texture loads in the wrong project if you don’t close the modkit everytime you needs to swtich projects

**Sintoma:** Open modkit, create a new project named A, load textures through the file importer. Then create a new project named B. Right click on B and load textures through the files importer: files will appear inside of A’s texture folder instead of B’s. When making mods from empty project in the modkit, there is a bug where after finishing a project you have to close the modkit and open it again, otherwise all the files you import through the file importer ¡are imported intro the previous project your were working in, even though you are right-clicking on the new project. This happens every time without a fault. Just wanted to put it here in case there can be a fix in the next modkit hotfix, because

**Causa:** desconocida

**Solucion:** Hi @itsmechiie7 , just wanted to let you know that along with the other issue you reported earlier, this one has also been fixed in our October update. Thanks again for flagging it!
