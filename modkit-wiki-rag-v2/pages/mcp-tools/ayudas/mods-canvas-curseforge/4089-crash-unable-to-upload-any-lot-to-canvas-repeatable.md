# Crash: Unable to Upload Any Lot to Canvas (repeatable)

**Sintoma:** DirectX: 12 Hi team, I’m running into a repeatable crash any time I try to upload a lot to Canvas — even if the lot only has a single wall. This is preventing me from creating build content for the Cahaya Update , so I’d really appreciate assistance on this as soon as possible. Error type: EXCEPTION_ACCESS_VIOLATION (occurs only on upload) Game otherwise runs normally (can play/build without issues until upload attempt) Lot file size: ~13 MB (but happens even with empty/simple builds) What I’ve tested: Uploading a fully furnished lot → crash Uploading a shell build (no furniture) → crash Uploading a lot with just simple walls → crash Tested with/without CC (removed CC → still crashes) Saved/

**Causa:** desconocida

**Solucion:** Update on this issue: I removed everything from my InZoi Documents and InZoi BlueClient folder (except my Saved Games, Custom Data, and Photo folders), then fully uninstalled and reinstalled the game. It works fine now! Just wanted to share in case anyone else runs into the same problem
