But I am really wondering: for some lots there are nearly no builds yet and checking through the exisiting ones it seems to be only houses built recently in the last 1-2 months. Checked also for lots where I know for sure as I have uploaded lots myself some time ago, but these are not there. And newly uploaded are there. Is it that we only can find newly built lots with the new search option and the 10 months of people building houses in the past are locked out when using this option? Or am I missing something?
