# washing machine fails to clean

**Sintoma:** After clothes become dirty, the washing machine fails to clean them effectively, and the clothes remain visibly soiled. No mods are enabled.Only through this cheat code can freezeAllNeeds be avoided [true/false] The subject of occurrence is a child My child’s clothes are dirty. They can use the washing machine with the family, but the clothes are still dirty after washing. archive file My Files

**Causa:** desconocida

**Solucion:** Hi everyone ( @all )! This issue was fixed in v0.3.4 . Fixed an issue where doing “Ask to Do Laundry” as a child Zoi would not actually clean the clothes However, the following issue is still under investigation and remains on the Known Issues list. At the Bumi Indah House property, when a child Zoi tries to use the washing machine, the message “Another Zoi is using it” appears even when it is not in use. We’ll provide an update here as soon as we have more information!
