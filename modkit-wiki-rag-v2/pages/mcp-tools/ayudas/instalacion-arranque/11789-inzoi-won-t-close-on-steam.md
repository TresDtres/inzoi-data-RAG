# Inzoi won’t close on Steam

**Sintoma:** The same happens if I click stop and Shutdown appears, it never completes successfully. The only way is to restart the PC

**Causa:** desconocida

**Solucion:** Sometimes I have a similar problem. After exiting the game and saving, it takes forever for anything to happen. Steam still shows inZoi as “open and in-game.” To get around this, when I want to close inZoi, I just select “Save,” return to the lobby, and then exit the game
