# Create a Zoi — “add Zoi” plus button missing; Complete returns to home screen instead of advancing to family tree and move-in step

**Sintoma:** The update installed correctly. The in-game v0.10.0 feature tour played on first launch, and the other new Create a Zoi content works normally. Newborn and toddler age groups are present and function as expected, and the new custom voices are present. What is missing / not working: The plus button beneath the Zoi’s portrait and the portrait itself, used to add another Zoi to the household, is not present. Because that button is missing, the genetics system cannot be reached at all. There is no way to add a second Zoi. Clicking Complete does not advance to the family tree screen. Instead the game returns to the home screen, so the move-in step where the household’s home is chosen is never rea

**Causa:** desconocida

**Solucion:** Hey there, I just tried to reproduce your bug thanks to your detailed report and then noticed that you’re in Character Studio (visible in your screenshots; upper left corner). If you want to create more than one Zoi in a new save and send them to the world directly, you need to choose “new save” in the main menu of the game. Character Studio is simply a tool to design zois or outfits, e.g. to save them as preset or to upload them on Canvas without having to start a new save Hope this helps!
