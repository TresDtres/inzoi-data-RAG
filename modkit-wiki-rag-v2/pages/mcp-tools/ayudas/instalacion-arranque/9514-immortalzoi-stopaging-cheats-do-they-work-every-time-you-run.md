# ImmortalZoi + stopAging cheats - do they work every time you run the game?

**Sintoma:** Do I have to enter the code every time I launch the game to make Zoi immortal and prevent aging? Or is it enough to enter these codes once and the game will remember the settings after loading the save? I have aging disabled in the options, but the age progress indicator on Zoi’s control panel still moves. The same applies to weather and seasons - if I want a specific season to last, for example, 20 simulation days, do I have to enter that code again every time I load the save?

**Causa:** desconocida

**Solucion:** Consequences or ‘effects’ of using cheats last for the active game session. They are not saved with the game. Cheats need to be reapplied every time a game is started. They are “cheats”, not options. They bypass the usual game play. Hence by design the consequences of applying cheats are not permanent across game saves
