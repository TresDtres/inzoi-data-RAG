# Unable To Launch Cahaya DLC Even Though STEAM Installed It (UPDATE)

**Sintoma:** ISSUE HAS BEEN RESOLVED. It appears it was taking either Steam and/or the game itself to realize the new DLC was installed. For me this was some 45min to 1hr after I downloaded/installed the DLC on Steam. For those Zoiers who’re trying to load an existing save game family, let Steam auto downlaod and update the game with the DLC, then ran into this this issue, try these: Disable mods from the game menu screen and then exit the game. This ensures you’re launching the save from an unmodded status completley clean Go into your Steam library and revalidate all the Steam files (will take a little while) Launch the game (mods are disabled right?) and load your save game.
