# Game is not saving on Mac Steam

**Sintoma:** Open application, start new game, play game as normal, save game, return to lobby, return to start page, quit application , quit steam, reopen steam, reopen application, on start page there is not option to load previously played game, only to start a new game Cannot upload .usvx save files to this post since that selection was greyed out for this file type but sharing the link from the upload: Webfolder /b56d313a by file.kiwi 56.56 1920×1014 192 KB

**Causa:** Mac permission access settings

**Solucion:**

1. Go to System Settings > Privacy & Security > Files and Folders and check if inZOI has been properly added
2. If inZOI is not listed, uninstall inZOI via Steam and restart your Mac
3. After restarting your Mac, reinstall inZOI via Steam
