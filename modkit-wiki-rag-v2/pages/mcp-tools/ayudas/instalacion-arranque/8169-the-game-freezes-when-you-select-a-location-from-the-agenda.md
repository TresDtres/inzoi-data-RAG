# The game freezes when you select a location from the agenda

**Sintoma:** The game freezes when I select Smartphone > App > Select a location This happened to me with two different Zois, selecting Turtle Sanctuary and Serene Beach. Each time I have to close the game from Steam, so I haven’t tried with other locations

**Causa:** desconocida

**Solucion:** Hello everyone( @here ), First of all, we sincerely apologize for the inconvenience this issue may have caused. Thanks to your reports, we were able to identify a game freeze that occurred when entering the schedule window under certain language settings. This issue has now been resolved with the v0.5.2 hotfix . Once again, we’re sorry for the disruption. As this matter has been addressed, we’ll be closing this post—but if you encounter any new issues or have additional reports, please don’t hesitate to let us know
