# Game Crash After choosing an City

**Sintoma:** Start game, Create a new Zoi (random or detailed, doesn´t matter, works until here), click through to the city selection, select an city, doesnt matter which→Loading screen and Crash to Desktop without an error Instruction: No Save file available The error exist since the anniversitary update and isnt fixed in any of the followed hotfixes. the game even dont create any of the ini files (engine etc.) in the AppData/Local/InZoi…. which are recommended to delete in this issue to force a recreating of these (tried to fix it on my own and went back to clean install after each try) As an technical person im at my witts end….help pls

**Causa:** desconocida

**Solucion:** @DasBombi , DasBombi: Result : The Folder “Saved” doesnt exist in the game files in my steam installation. There is an error in the path to the ini files in the topic Resolving Crash Issues. The correct path for the ini files on Windows is C:\Users\UserName\AppData\Local\BlueClient\Saved\Config\Windows Try removing the ini files from this path as suggested. @AR_Luna , Path to ini files in the topic Resolving Crash Issues After the Latest Update Step 4 , is incorrect. For Windows, the path should be C:\Users\username\AppData\Local\BlueClient\Saved\Config\Windows
