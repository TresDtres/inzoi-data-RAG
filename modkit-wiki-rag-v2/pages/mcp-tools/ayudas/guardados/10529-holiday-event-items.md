# Holiday Event Items

**Sintoma:** I collected all the holiday objects in December while playing with only one family. Now I wanted to use them for a different family and it turned out they are not available in build mode for that lot. Does this mean that if I change the save or reset the lot, those objects will disappear completely?

**Causa:** desconocida

**Solucion:** Some of the winter event objects and items were only collectable during that specific event, just like with the Halloween one. The team said, they’ll make them available for everyone 24/7 once they implement the calendar system. You can however use these items with the families you’ve gathered them with. They’ll remain activated for them. I’ll move this thread to the Q&A section, since this is not a bug, but designed to work that way for now. Feel free to browse the Wishlist category, because there are various threads about improvements for this specific in-game system already
