# [V0.8.5] Minimap is displayed on opening a saved game though Game Options is set to OFF

**Sintoma:** Win11 Pro 23H2, i7-13700K, NVidia RTX 4070 Ti, 64 GB DDR5 Set Options>Control Set Minimap display to OFF. Start a game. Save the game. Open the saved game. Minimap is displayed though the Game Options for the Minimap is set to OFF. Minimap is displayed on opening a saved game or a new game, though Game Options>Control setting is set to OFF. Toggling the setting in the game options switches off the Minimap. However, when the saved game is reloaded or opened, the Minimap is again displayed though the game setting for the Minimap is OFF

**Causa:** desconocida

**Solucion:** Solved in v0.9.4. Minimap setting in game Options set to OFF, now does not display the minimap in the game
