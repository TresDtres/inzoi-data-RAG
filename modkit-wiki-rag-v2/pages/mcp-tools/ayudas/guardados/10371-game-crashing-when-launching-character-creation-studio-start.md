# Game crashing when launching character creation studio/starting a new save

**Sintoma:** OS version: Windows 11 (10.0.26200 Build 26200)

**Causa:** desconocida

**Solucion:** Hey there, welcome to the inZOI forum! Thank you for reporting this crash issue. Unfortunately, we’ve had various reports about crashes with game versions after the December updates. Since you’re using mods, please try to disable them before going into CAZ as either New Game or CAZ itself. Big new updates tend to corrupt many mods which then leads to those crashes. If this does not fix your problem, please try to switch back to the available older inZOI version. You can find it in the Steam inZOI settings > game versions & betas > 2025-12-22. Then report back whether either of these suggestions fixed the crashes
