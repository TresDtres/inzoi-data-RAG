# When saving a ZOI as preset, only “Everyday” outfit is saved?

**Sintoma:** Create a new Zoi and all the outfits > Save Preset > Create New Game > Load Preset So that’s why I’m creating the thread. When creating a new zoi, you meticulously choose all the outfits, save preset… and when you try to create a new game with this zoi and you load the preset, only “Everyday” outfit is loaded! All the other ones you have to recreate one by one

**Causa:** this, if a Winter outfit is applied while the Everyday category is selected, the Winter outfit is applied to the Everyday outfit

**Solucion:**

1. Outfits for each situation are not saved as a single set, so applying one preset does not apply outfits to all categories
2. Here is the instruction on how to apply a preset correctly
