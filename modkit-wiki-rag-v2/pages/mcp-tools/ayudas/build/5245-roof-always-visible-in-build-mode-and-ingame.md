# Roof always visible in Build mode and ingame

**Sintoma:** When replacing a roof or part of a roof, the new roof will sometimes get ‘stuck’ on screen so that it’s always visible, even on the lowest floor with all walls cut away (see screenshot below). You can still move, delete it etc., but there’s no way to stop it from showing up without deleting it altogether. I’m not sure what causes this, but it’s happened to me now with 3 different families in different cities, so it’s definitely not just one particular save. It’s not such a big issue for small side buildings like this one, but if it’s a large roof on a main building, it makes gameplay almost impossible as you can’t see anything underneath. The only option is to reload a save to get the origin

**Causa:** desconocida

**Solucion:** Hi @Liessahl . Glad to hear that it’s working now! Just to note — when the roof is generated, please make sure it’s placed on the second floor (upper floor) . This will ensure the roof to disappear correctly when it should. Since it is working now, I will close this thread. If you need other help, don’t hesitate to create a new thread
