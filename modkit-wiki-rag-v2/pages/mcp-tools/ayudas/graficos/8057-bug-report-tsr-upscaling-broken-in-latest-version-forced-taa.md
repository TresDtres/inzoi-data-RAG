# Bug Report: TSR Upscaling Broken in Latest Version – Forced TAA on DLSS Settings

**Sintoma:** Issue Summary: Since the latest update, the Temporal Super Resolution (TSR) functionality is no longer working as intended. It currently only activates when the DLAA option is selected. In all other DLSS/Upscaling modes, the game defaults to standard TAA , resulting in significantly lower visual quality. Detailed Description: Previous Behavior: In the previous version, TSR could be enabled and functioned correctly across various upscaling presets. Current Behavior: In the current version, selecting any DLSS/upscaling option (other than DLAA) fails to trigger TSR. Instead, the game forces TAA , which causes a blurry image and poor anti-aliasing performance compared to the previous build. Impa

**Causa:** desconocida

**Solucion:** Hi @Mahiru , To prevent potential rendering issues in inZOI, TSR is intentionally enabled only when DLAA is selected. Please keep this in mind when adjusting your settings
