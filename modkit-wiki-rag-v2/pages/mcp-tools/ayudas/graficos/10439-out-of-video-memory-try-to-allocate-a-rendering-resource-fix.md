# “Out of video memory try to allocate a rendering resource…” fix

**Sintoma:** Processor AMD Ryzen 7 7735HS with Radeon Graphics (3.20 GHz) Installed RAM 16,0 GB (15,2 GB usable) System type 64-bit operating system, x64-based processor Pen and touch No pen or touch input is available for this display I tried everything under the sun to make the error go away, and the only thing that worked was me changing my version to a previous one and back to the new one. When I launched the game, everything was moving smoothly and perfectly. I did try and verify the integrity of the files, which said it was at 100%, but changing versions clearly fixed the problem that I couldn’t get fixed until I did that. Thank you to the devs who suggested I try and play on an older version for t

**Causa:** desconocida

**Solucion:** I have this same issue and you’re not really dealing with a version issue, you’re dealing with Inzoi being RAM hungry. After a bit, if too much happens, the game spikes in its usage and you get that error. The only fix I have found thus far is to lower the load by turning off Ray tracing if you have it on, and then lowering the graphic settings a level so long as you have the issue. I have a system that shares your exact Installed RAM and this helped me, so I think it would help you too. I am sorry that I cannot provide better advice, but I hope this helps. Also, the next engine update is supposed to help with stability, so perhaps give it a try after March 5th and see if it helps your game
