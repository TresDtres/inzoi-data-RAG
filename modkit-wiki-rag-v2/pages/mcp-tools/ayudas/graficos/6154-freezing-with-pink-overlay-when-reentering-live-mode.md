# Freezing with Pink Overlay when Reentering Live Mode

**Sintoma:** Windows 11 Home 24H2, Intel Core i7-12650H 2.70 GHz, NVIDIA GeForce RTX 4060 Laptop GPU, 8 GB VRAM, 32 GB RAM 4800 MT/s, 1 TB Storage (general case): In Live Mode, enter residential Build Mode or Edit Public Property Build Mode Return to Live Mode. The screen may flash or temporarily freeze with a pink overlay. The bigger the lot and/or the more congested the area, the longer the frozen state persists. If the flash or freeze doesn’t occur, put more items in the room, or move the camera to a different room that has more items, and see if it occurs then. For a Clear and More Servere Case: Go to Cahaya’s Resort Facilities and enable the “EditAllSite True” cheat Open the “Edit Public Property” B

**Causa:** desconocida

**Solucion:** Repeated testing has confirmed that color and material can be changed when initially creating an object, but cannot be modified after construction is complete . Any attempt to modify will inevitably cause the game to crash. This bug has persisted for a long time and needs to be resolved as soo
