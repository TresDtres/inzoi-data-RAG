# Graphic Card Notification

**Sintoma:** But since the update on Thursday, I’ve had this message pop up when opening InZoi. I went into the graphics card settings and it says its up to date. It seems to run ok, maybe a couple of visual glitches but nothing drastic. Is this happening for anyone else, and also what has changed? Screenshot 2026-09-04 154222 708×417 102 KB

**Causa:** desconocida

**Solucion:** If you have a laptop - download the driver from this link: https://us.download.nvidia.com/Windows/616.64/616.64-notebook-win10-win11-64bit-international-dch-whql.exe If you have a desktop computer - then from this one: https://us.download.nvidia.com/Windows/616.64/616.64-desktop-win10-win11-64bit-international-dch-whql.exe And just install it, keeping your current settings. There’s nothing complicated there, just click “Next” everywhere
